# v0.4 文字認識そのものの改善 — 2026-10-29

対象: https://yomiageman.tadacid.chatgpt.site/?v=4 （本人限定、試作）

## 変更点

v0.3の16表現の置換を製品コード・設定画面から除去した。新しい認識結果に単語辞書の置換はかけない。過去の実装はローカルの `experiments/v03-phrase-correction/` に保存しており、公開アプリには含めない。

- PP-OCRv5 mobileから、日本語対応の公式PP-OCRv6 small ONNXへ交換。固定リビジョン `b8f84f0b80c529de40b4fbb3544b84fa7233a513`。モデル約21MB、OCR資産合計約32MB。モデルの出典・SHA256は `dist/vendor/paddle-v6/source.json`。
- 文字の黒い部分だけで切り詰めず、行高の16%の余白を追加して、薄い輪郭・小書き文字・濁点を保持。
- 本文を傾き補正・行分離後、黒い文字の高さ14pxと18pxに正規化した2入力で照合。結果が異なる行だけ16pxでも確認。
- 行が2回一致すればその結果を使用。3結果で同じ文字数なら文字位置ごとの多数決を使用。文字数が異なり行の一致もない場合、または同じ位置の3文字がすべて異なる場合は保留。モデルの確信度だけで誤読を採用しない。
- モデル内の文字一覧とCTC復号は必要だが、決まった単語・文の置換辞書は使わない。
- 映像・認識文の外部送信、外部OCR API、課金サービスは追加していない。標準会話欄の自動検出と読み上げ待機は従来どおり。

## 実画像の比較

比較対象はv0.3の置換を無効にした状態（OCRはv0.2と同じ）。空白・改行と全角半角を正規化し、文字の編集距離を比較。

| 画像 | 条件数 | 旧OCRの誤り | v0.4の誤り | v0.4本文完全一致 |
|---|---:|---:|---:|---:|
| 「今日はどこまで…いっしょに行くよ」 | 4 | 8 | 0 | 4/4 |
| 「ウチの背中のタネもね…咲くんだよー！」 | 2 | 2 | 0 | 2/2 |

1枚目は元画像・縦配置・縮小・4度の傾斜。2枚目は1920px幅と960px幅。画像は2枚だけで、ゲーム全体の精度を表す数字ではない。調整中にもこれらの画像を使ったため、未見データだけの厳密な性能評価でもない。

- [公式の画像1](https://www.pocoapokemon.jp/assets/img/howtoplay/251113_04/ja/img_01.webp)
- [株式会社ポケモンの画像2](https://files.corporate.pokemon.co.jp/files/user/topics_img/8/2/02.PNG)
- 結果: `ocr-v04-vision.json`、`ocr-v04-corpus.json`。旧画像1の結果: `ocr-v02-results.json`。
- 会話のない画像は空の結果になり、誤って読み上げる文を生成しなかった。
- 写真を選ぶ実アプリ操作でも「いっしょ」の表示を確認。音が実際に聞こえたこと、iPhoneの音声継続再生は未確認。

## 別文章の比較と残る誤り

ブラウザのsans-serifとserif、28pxと36pxで合成した36文章、144パターンを確認。ゲーム固有フォント・カメラ撮影の代わりになる試験ではない。

| 合成画像の集合 | 件数 | 旧OCR完全一致 | v0.4完全一致 | 旧→新の編集距離合計 |
|---|---:|---:|---:|---:|
| 比較・調整用24文章 | 96 | 94 | 94 | 15→15 |
| 追加12文章 | 48 | 45 | 43 | 3→5 |
| 合計 | 144 | 139 | 137 | 18→20 |

追加文章の明朝体系では「ニャース→ニヤース」「かっぱ→かつぱ」「りょうり→りようり」が残った。5条件が旧版から悪化し、別の3条件は改善した。比較用集合の2条件は新旧とも会話欄の検出で見落とし。「どんな文章でも改善した」「小書き文字の問題を解決した」とは言えない。今回改善した根拠は実ゲームの公式会話画像に限られ、他のフォントでは退行もある。

## 検証と速度

- ユニットテスト20件、JavaScript構文チェック、静的ビルド。
- 同じ実画像の継続認識は約316〜348ms/画像、初回680ms（Macの内蔵ブラウザ、ローカルモデル取得を含む）。2タブで検証を並行実行中の測定で、単体性能ベンチマークではない。
- 旧版より推論回数が2〜3倍になる。iPhone/iPadの速度、発熱、メモリ、実カメラ映像での精度と連続音声再生は未確認。
- カメラの反射・ぼけ・遠距離・強い台形ひずみは今回の検証に含めない。

## 再現

`npm ci --ignore-scripts`、`npm run setup:model`、`npm run build`、`npm test`、`npm run check`、`npm run dev`。

画像1を `build/reference-dialogue.webp`、画像2を `build/ocr-v04/heldout.png` に置き、`/__test/vision.html` を開く。比較ページ ` /__test/corpus.html` には、v0.3の旧distを `build/ocr-v04/dist-v03/` に置く必要がある。旧ソースのコミットは `7293e3d782d5ad96b456cd76b835fb97b30a1549`。比較ページが自動で旧版の単語補正を無効にする。

検証ページ、ゲーム画像、比較用モデルは公開用 `dist/` に含めない。
