# よみあげマン（Web試作 v0.5）

iPhone / iPad のカメラをゲーム画面に向け、下側の標準会話欄を自動で探して読み上げるアプリです。Developer Program・毎週の再インストール・使用中のMacは不要です。

本人限定URL: https://yomiageman.tadacid.chatgpt.site/?v=5

## 今回の改善

文字認識は正しく読めているのに、読み上げなかった4つの場合を直しました。文字認識のしくみはv0.4と同じです。

- 「わーい！」「えっ！？」「……ありがとう。」のように、記号・「ー」・「……」の多い短いセリフも読み上げます。
- 2文字ほどの短いセリフでも会話欄を見つけます。文字のない会話欄は対象にしません。
- 反射やピントの揺れで認識が一度保留になっても、同じセリフが出ている間は読み上げまで進めます。会話欄が2.5秒続けて消えたときだけ、会話の終わりとみなします。
- 赤・青・緑などの濃い色の文字を消さずに読みます。色付きの文字だけのセリフも対象です。会話欄の紫の縁、背景、次へ進む「▼」は従来どおり除きます。

修正前後を同じ画像で比べると、短いセリフ・「……」入りの27件は4件→27件、色付きの単語を含む7件は5件→7件を正しく読み上げました。色付きの文字だけの7件もすべて読み上げました。v0.4の検証で使った合成144条件の完全一致は137件→139件です（会話欄の見落とし2件を解消）。誤りが増えた条件、会話のない画像で読み上げた条件はありません。静止画での限定的な確認で、実カメラでの精度を保証するものではありません。詳細は [読み上げ判定の検証](docs/読み上げ判定-v05.md)。

## 文字認識のしくみ（v0.4から）

- 日本語対応の公式PP-OCRv6 small認識モデルを使用。
- 文字の輪郭や濁点を切り落とさないよう、行の切り出しに余白を確保。
- 同じ行を異なる大きさで認識し、2回が一致した結果を採用。食い違うときだけ3つ目の大きさでも確認し、文字単位でも一致を確認し、不一致が残れば読み上げを保留。
- 単語辞書による置換はなし。表示と読み上げには同じ認識結果を使用。

v0.4では、公式会話画像2枚・6条件で旧OCRの誤り合計10文字が0文字になりました。明朝体の「ゃ・ゅ・ょ・っ」の誤り（例: ニャース→ニヤース）は残っています。詳細は [文字認識の検証](docs/文字認識-v04.md)。v0.3の16表現補正は [過去の記録](docs/かな補正-v03.md) であり、現行版には含みません。

## 使い方

Safariで公開URLを開き、画面左上の「試作 v0.5」を確認。「はじめる」でカメラを許可し、ゲーム画面をなるべく正面から大きく映します。文字が出そろい認識が安定すると読み上げます。同じ文章は連続で読みません。「写真でためす」でも確認できます。

映像・認識文をサーバーへ送るコードはありません。音声と速度の設定のみ端末内に保存します。音声はブラウザの日本語音声を使い、ローカル音声を優先します。初回は約32MBのOCRプログラム・モデルをダウンロードします。旧版より処理が増えるため、端末によって読取待ち時間が長くなる可能性があります。

## 残っている制約

- 誤認識・見落としは残ります。カメラの反射、ピンぼけ、斜め撮影への耐性は未完成です。
- 標準の下側会話欄が対象。メニュー、選択肢、頭上の吹き出しは対象外です。
- 日本語1文字だけのセリフ（「え？」など）は、雑音と区別するため読みません。
- 今回のiPhone / iPad実機での認識速度・連続音声再生は未確認です。
- 画面を開いている間だけ動作。画面ロック・別アプリへ移動すると停止します。
- ブラウザにキャッシュを削除されることがあり、完全なオフライン動作は保証しません。

## ローカルでの開発と確認

```sh
npm ci --ignore-scripts
npm run setup:model
npm run build
npm test
npm run check
npm run dev
```

http://127.0.0.1:4173/ はMacのローカル検証用です。iPhoneでは公開URLを使います。

`web/` が製品コード、`scripts/` がビルド、`tests/` が検証です。`experiments/` は不採用・過去の実装で製品に含みません。ゲーム参考画像と検証ページはローカル専用で、公開する `dist/` に含めません。課金サービス・外部OCR APIは追加していません。

実画像検証は `docs/文字認識-v04.md` の手順を参照してください。
